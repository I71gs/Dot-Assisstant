# Legacy Archive

This directory contains `DotAssistant.py` — the original monolithic voice assistant script.

It has been superseded by the modular Phase 1 architecture in `core/`, `modules/`, and `services/`.
Run the assistant with:

```
python main.py
```

`DotAssistant.py` is kept here purely as a historical reference. It is **not used** by the current codebase.
